# Compressor Overviews

The **Online Laboratory for Data Compression in Climate Science and Meteorology** allows you to explore various data compression approaches. Compressors are made up of one or more codecs that transform and/or compress the data. The following notebooks introduce several popular scientific compression codecs and showcase how they can be applied.


## Overview of the provided notebooks

- [`01-bit-round.ipynb`](01-bit-round.ipynb): Bit rounding
- [`02-zfp.ipynb`](02-zfp.ipynb): ZFP
- [`03-sperr.ipynb`](03-sperr.ipynb): SPERR
- [`04-ebcc.ipynb`](04-ebcc.ipynb): EBCC
- [`05-lc.ipynb`](05-lc.ipynb): LC
- [`06-sz3.ipynb`](06-sz3.ipynb): SZ3
- [`07-pressio.ipynb`](07-pressio.ipynb): LibPressio
- [`08-safeguards.ipynb`](08-safeguards.ipynb): Compression Safeguards
- [`09-random-projection.ipynb`](09-random-projection.ipynb): Random Projection
