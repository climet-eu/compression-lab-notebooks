# Example walkthroughs of applying data compression

The **Online Laboratory for ESiWACE3 Data compression hackathon** allows you to explore various data compression approaches. Compressors are made up of one or more codecs that transform and/or compress the data. The following notebooks provide several walkthroughs for different compression scenarios to introduce you to the available codecs and how they can be applied and evaluated.


## Overview of the provided notebooks

- [`01-bit-round.ipynb`](01-bit-round.ipynb): Introduction about the bit-round compressor
- [`02-zfp.ipynb`](02-zfp.ipynb): Introduction about the zfp compressor
- [`03-sperr.ipynb`](03-sperr.ipynb): Introduction about the sperr compressor
- [`04-ebcc.ipynb`](04-ebcc.ipynb): Introduction about the ebcc compressor
- [`05-lc.ipynb`](05-lc.ipynb): Introduction about the lc compressor
- [`06-sz3.ipynb`](06-sz3.ipynb): Introduction about the sz3 compressor
- [`07-pressio.ipynb`](07-pressio.ipynb): Introduction about the pressio compressor
- [`08-safeguards.ipynb`](08-safeguards.ipynb): Introduction about the safeguards compressor suite
