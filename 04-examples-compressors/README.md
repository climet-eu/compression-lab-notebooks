# Example walkthroughs of applying data compression

The **Online Laboratory for ESiWACE3 Data compression hackathon** allows you to explore various data compression approaches. Compressors are made up of one or more codecs that transform and/or compress the data. The following notebooks provide several walkthroughs for different compression scenarios to introduce you to the available codecs and how they can be applied and evaluated.


## Overview of the provided notebooks

- [`01-intro-numcodec.ipynb`](01-intro-numcodec.ipynb): Introduction about the numcodecs
- [`02-bit-round.ipynb`](02-bit-round.ipynb): Introduction about the bit-round compressor
- [`03-zfp.ipynb`](03-zfp.ipynb): Introduction about the zfp compressor
- [`04-sperr.ipynb`](04-sperr.ipynb): Introduction about the sperr compressor
- [`05-ebcc.ipynb`](05-ebcc.ipynb): Introduction about the ebcc compressor
- [`06-lc.ipynb`](06-lc.ipynb): Introduction about the lc compressor
- [`07-sz3.ipynb`](07-sz3.ipynb): Introduction about the sz3 compressor
- [`08-pressio.ipynb`](08-pressio.ipynb): Introduction about the pressio compressor
- [`09-safeguards.ipynb`](09-safeguards.ipynb): Introduction about the safeguards compressor suite
